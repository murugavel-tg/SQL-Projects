# 🗄️ SQL Projects

## 📌 Project Overview

This repository contains SQL projects demonstrating practical skills in data querying, data cleaning, analysis, reporting, and business problem-solving.

The projects are designed to demonstrate how SQL can be used to transform raw data into meaningful insights and support data-driven decision-making.

---

## 🛠️ SQL Skills Demonstrated

- SELECT statements
- Filtering with WHERE
- GROUP BY and HAVING
- ORDER BY
- Aggregate Functions
- CASE Statements
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date and Time Functions
- Data Cleaning
- Business Analysis

---

## 📂 Projects

### 1. Sales Analysis
Analysis of sales performance, revenue, products, customers, and regional trends.

### 2. Customer Analysis
Analysis of customer behavior, purchasing patterns, and customer segmentation.

### 3. Business KPI Analysis
SQL queries designed to calculate and monitor important business performance indicators.

### 4. Advanced SQL Analysis
Examples using CTEs, subqueries, window functions, and advanced analytical queries.
